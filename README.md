# learning-state

Dedicated persistence branch for generated public Trilha A state only.

This branch is intentionally not a source-code branch. It stores only public candle partitions under learning/data/, generated collection-quality reports under learning/reports/, and generated educational backtest output under learning/experiments/. Source code and tests remain on the code branches.

No real collection was executed to create this branch. It starts with placeholders; the scheduled collector will populate state only when run separately.
