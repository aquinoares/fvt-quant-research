# Alertas por falha de workflow

Este documento contém instruções para o responsável. Nenhuma configuração de notificações foi alterada.

1. Entre no GitHub e abra as configurações pessoais de notificações.
2. Revise as opções de e-mail e de notificações de GitHub Actions para repositórios que você acompanha; habilite alertas de falha quando a interface atual oferecer esse filtro.
3. Em `aquinoares/fvt-quant-research`, confira as configurações de watch/notificações do repositório e escolha o nível apropriado para execuções/falhas de workflows.
4. Faça uma execução de teste apenas em um workflow seguro e permitido, e confira a caixa de entrada e spam. Não use nem reabilite o workflow P6-MOM Cloud Shadow Live para testar notificações.
5. Como alternativa, acompanhe Actions → workflow → execução e os logs da execução.

Os nomes exatos das opções podem variar conforme a interface atual do GitHub e as preferências pessoais. Não adicione e-mails, tokens ou credenciais aos arquivos do repositório.
