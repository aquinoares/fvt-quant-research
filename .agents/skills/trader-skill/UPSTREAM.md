# Upstream attribution

The project-local trader-skill is an adaptation of the research workflow concepts in:

- Project: HKUDS/Vibe-Trading
- Repository: https://github.com/HKUDS/Vibe-Trading
- Upstream skill: agent/src/skills/strategy-generate/SKILL.md
- Upstream skill URL: https://github.com/HKUDS/Vibe-Trading/blob/main/agent/src/skills/strategy-generate/SKILL.md
- Upstream license: MIT — https://github.com/HKUDS/Vibe-Trading/blob/main/LICENSE

The upstream repository does not contain a skill literally named trader-skill. This repository adds a new, adapted skill for its own OHLCV validator, causal spot backtest and frozen-track constraints. It does not vendor the Vibe-Trading application or copy its backtesting engine.
